# matteopuglisi.it

Sito di **Matteo Puglisi, Chinesiologo**. Acireale e Catania.

Pagine in HTML, CSS e JavaScript puri: nessun framework, nessuna libreria esterna,
nessun passo di compilazione. I caratteri sono locali, non si chiede niente a nessuno.

Questo repository contiene **solo il sito pubblicato**. Il lavoro di progettazione
sta in un repository privato.
